# Guia 30/300

Clone estatico recuperado do site publicado no Lovable.

## Rodar localmente

```powershell
node server.mjs
```

Depois acesse http://localhost:5173.

## Observacao

Este repositorio contem o build publicado/minificado, com HTML, CSS, JS e assets. Ele preserva o visual e as rotas do site, mas nao contem os arquivos-fonte originais do editor Lovable.
